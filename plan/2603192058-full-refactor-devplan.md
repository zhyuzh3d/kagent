请认真阅读和理解 [_service_standard.md](doc/_service_standard.md) service开发标准文档内容，然后严格按照这个文档的标准，分步骤执行以下任务：

1、 pkg/hubsvc 基础设施包的兼容性代码重构和升级，目标是实现完全符合标准文档要求的hub-service基础协作契约和相关机制，最终必须实现功能完整、去除冗余的编码结果。

2、 pkg/toolproto 基础设施包的兼容性代码重构和升级，目标是实现完全符合标准文档要求的工具tool完整协议和公共逻辑，最终必须实现功能完整、去除冗余的编码结果。

3、 hub项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的标准文档规定的全功能hub模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动开发，有计划、分步骤的稳定实现全部开发计划。

4、 services/file_storage项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的文件和blob数据存储基础功能工具集模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动全自主开发，有计划、分步骤的稳定实现全部开发计划。（注意，后续其他模块的文件blob存储功能都应通过hub调用此模块工具实现，其他模块内部不应直接执行文件blob相关操作）

5、 services/sql_db项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的sqlite数据库操作基础功能工具集模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动全自主开发，有计划、分步骤的稳定实现全部开发计划。（注意，后续其他模块的sqlite数据库操作都应依照规范通过hub调用此模块工具实现，其他模块内部不应直接执行sqlite相关操作）

6、 services/account项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的账号应用层功能工具集模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动全自主开发，有计划、分步骤的稳定实现全部开发计划。（注意，Hub 负责统一识别请求来源的User-Id并注入上下文，account基于 Hub 注入的受信身份执行具体的业务鉴权与授权）（请参考webui/page/account页面相关功能，以工具集形式提供全部所需功能）

7、services/ai_doubao项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的基于doubao接口的ai对话相关基础功能工具集模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动全自主开发，有计划、分步骤的稳定实现全部开发计划。（注意，ai_doubao只实现基础工具，聊天应用层相关功能在chat_server模块实现）

8、services/chat_server项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的AI对话聊天相关应用层工具集模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动全自主开发，有计划、分步骤的稳定实现全部开发计划。（注意，chat_server中的ai相关功能都应通过hub调用ai_doubao工具集实现，禁止chat_server自身直接调用外部接口实现功能）（请参考webui/page/chat页面相关功能，以工具集形式提供全部所需功能）

9、services/surface-manager项目全面重构和优化，目标是实现完全符合标准的、功能完整、去除冗余的surface管理工具集模块。你要先 plan 模式深度分析这个项目，然后撰写专业严谨的开发计划，然后以 dev 模式启动全自主开发，有计划、分步骤的稳定实现全部开发计划。（注意，surface-manager中的数据库、文件、ai等功能都应通过hub调用其他模块工具集实现，禁止surface-manager自身直接自身重复实现其他模块已经提供工具的功能）（请参考webui/page/surface页面相关功能，以工具集形式提供全部所需功能）

10、深度分析检查webui/page/account页面相关代码，dev 模式执行改进，确保其全部请求都指向hub提供的正确的工具集（源自account提供）。

11、深度分析检查webui/page/chat相关页面功能，dev 模式执行改进，确保其全部请求都指向hub提供的正确的工具集（源自chat_server或ai_doubao提供）。

12、深度分析检查webui/page/surface相关页面功能，dev 模式执行改进，确保其全部请求都指向hub提供的正确的工具集（源自surface-manager提供）。
